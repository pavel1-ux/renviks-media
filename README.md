# Готовые ролики РЕНВИКС

Сюда контент-завод кладёт одобренные рилсы, обложки и слайды. Отсюда их забирает vidIQ для публикации в Instagram @renviks.remont.

## Телеграм-автопостинг (@rrenviks)

- `telegram/queue/ГГГГ-ММ-ДД.json` — пост на этот день. Публикуется каждый день в 10:13 по Москве.
- `telegram/media/` — видео и фото для постов.
- `telegram/posted.txt` — что уже опубликовано (заполняется автоматически).
- Секреты репозитория: `TG_BOT_TOKEN`, `TG_CHAT_ID` (= `@rrenviks`).
- Ручной запуск: Actions → «Телеграм — пост дня» → Run workflow (можно указать дату).
